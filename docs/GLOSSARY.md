# BudgieMac glossary

One name per idea. Every word on screen (buttons, menus, titles, tooltips,
errors, VoiceOver labels) comes from this table. Add a row before using a
new term.

## Things

| Term | Means | Not |
| --- | --- | --- |
| Account | A place money is held or owed: bank, credit card, loan, investment or cash | wallet, ledger |
| All Accounts | The sidebar page that lists every account with totals | Dashboard, Home, Overview |
| Account type | Bank, Credit Card, Loan, Investment or Cash; fixed after the account is added | kind |
| Opening balance | The balance an account had before its first transaction in BudgieMac; fixed after adding | starting balance, initial balance |
| Balance | Opening balance plus every transaction | current balance, computed balance |
| Cleared balance | Opening balance plus cleared and reconciled transactions | bank balance, available |
| Remaining credit | Credit limit plus balance, for credit cards with a limit | available credit, headroom |
| Transaction | One movement of money in one account, with a date, payee, amount and optional category | entry, record, item |
| Register | Internal word for an account's transaction list; on screen the page is titled with the account name | Transactions (as a page title), ledger |
| Payee | Who the money went to or came from | merchant, vendor, description |
| Category | A label that says what money was for; can sit under a parent category | tag, class |
| Withdrawal | Money leaving an account; stored as a negative amount | debit, payment, spend, outflow |
| Deposit | Money arriving in an account; stored as a positive amount | credit, income (as a field), inflow |
| Transfer | A pair of linked transactions moving money between two of your accounts | move, internal payment |
| Uncleared | A transaction your bank hasn't processed yet | pending, unconfirmed |
| Cleared | A transaction your bank has processed | confirmed, posted |
| Reconciled | A cleared transaction matched to a bank statement and locked by a reconciliation | verified, closed |
| Reconciliation | Matching an account's cleared transactions to a statement balance, then locking them | balancing, statement check |
| Scheduled | The sidebar page for repeating transactions | Subscriptions, Recurring, Bills |
| Scheduled transaction | A transaction that repeats on a rule and can be recorded each time it's due | subscription, scheduled payment, schedule, standing order |
| Next due | The date a scheduled transaction is next expected | next payment, due date |
| Forecast | Projected balance of one account from its scheduled transactions | projection, prediction |
| Budget | The sidebar page for envelopes and monthly amounts | plan |
| Envelope | A pot of money for some categories in a budget | bucket, pot, goal |
| Assigned | Money put into an envelope for a month | allocated, budgeted |
| Available to budget | Money received that hasn't been assigned to an envelope yet | to be budgeted, unassigned |
| Budgie data file | The file Budgie exports from Settings > Advanced > Export Data | portable package, data package, backup |
| Backup | A copy of all BudgieMac data the app keeps in its backup folder | snapshot, archive |

## Actions

| Term | Means | Not |
| --- | --- | --- |
| Add | Create a new account, transaction, category, payee or envelope ("Add Transaction") | New (in buttons), Create |
| Edit | Open something's fields to change them ("Edit Account…") | Modify, Update |
| Save | Keep changes made in an Edit sheet | Save Changes, Update, OK |
| Delete | Remove for good; Undo can bring it back during this session | Remove, Trash |
| Close Account | Hide an account that's no longer used; its transactions stay | Delete Account, Archive |
| Mark as Cleared / Mark as Uncleared | Change a transaction's cleared status | Clear, Tick, Toggle |
| Reconcile | Start a reconciliation for an account ("Reconcile…") | Balance, Match |
| Record | Turn a due scheduled transaction into a real transaction | Post, Enter, Pay |
| Skip | Move a scheduled transaction to its next due date without recording it | Ignore, Dismiss |
| Import Budgie Data | Replace all BudgieMac data with a Budgie data file | Restore, Load, Sync |
| Export Budgie Data | Write all data to a Budgie data file | Back Up, Save As |

## Retired Budgie names

| Budgie said | BudgieMac says | Why |
| --- | --- | --- |
| Subscriptions (page), Scheduled Transactions (launch list), Scheduled Payment (dialogs) | Scheduled, scheduled transaction | Salary and transfers aren't subscriptions or payments; one name everywhere |
| Accounts page and "Dashboard" in Open on launch | All Accounts | One name; "Accounts" is the sidebar section heading |
| Transactions (register title) | The account's name | The sidebar selection already says it's transactions; the name says which account |
| Single keys A, S, B, F, R | ⌘1 to ⌘4, ⌘R, ⇧⌘F (see S-049) | Mac apps use Command shortcuts in menus |
